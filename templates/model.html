SHAP Feature Importance

What signals matter most?

SHAP values reveal which URL features drive phishing predictions in our Random Forest model.

FEATURE 01
URL Length
Phishing URLs tend to be significantly longer to obscure the true destination domain.
FEATURE 02
IP Address in URL
Using a raw IP address instead of a domain strongly correlates with phishing and obfuscation.
FEATURE 03
Use of HTTPS
HTTPS absence is a phishing signal, though modern attackers increasingly use HTTPS too.
FEATURE 04
Subdomain Count
Multiple nested subdomains (paypal.com.malicious.xyz) are a hallmark of domain spoofing.
FEATURE 05
Domain Age & TLD Risk
Newly registered domains and high-risk TLDs (.xyz, .tk, .ml) skew heavily phishing.
FEATURE 06
Special Character Ratio
High density of @, %, !, = characters in the URL path indicates obfuscation or redirect chaining.
