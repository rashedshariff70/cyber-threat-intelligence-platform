About the Platform

Intelligent Threat
Intelligence Platform

CyberGuard is an end-to-end AI security platform that unifies phishing detection, network intrusion classification, and AI-powered security Q&A into one cohesive system.

🎯

Mission

To make advanced threat intelligence accessible through interpretable ML models and an intuitive interface — bridging the gap between raw data and actionable security decisions.

🧠

Methodology

Each module was built by comparing multiple algorithms (RF, LightGBM, XGBoost, KNN, Decision Tree, Logistic Regression) and selecting the best-performing model per task using stratified evaluation.

📊

Datasets

URL model trained on a custom phishing URL dataset with 48,820+ samples. Cyber attack model trained on UNSW-NB15 — a widely respected benchmark covering 5 attack categories.

🤖

LLM Integration

The AI assistant is powered by Groq's ultra-fast inference engine running Llama 3.3 70B Versatile — enabling real-time, context-aware responses about platform internals and cybersecurity topics.
